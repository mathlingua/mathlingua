== begin:description ==
Rejects documented mapping writing attached to a Declares target that is not a mapping.
== end:description ==
== begin:input ==
[\thing]
Declares: X
Documented:
. called: "thing"
. writing: f(x)
  as: "f(x)"
== end:input ==
== begin:output ==
error: Documented `writing:` is only allowed when `Declares:` targets a mapping
== end:output ==
