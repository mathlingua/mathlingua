== begin:description ==
Rejects a named subject in a function-type specification because function type specs require the `_` placeholder.
== end:description ==
== begin:input ==
[\set]
Declares: X
Documented:
. called: "set"

[\function:on{A}:to{B}]
Declares: f(x__) is (x "in" A) -> (_ "in" B)
when: A, B is \set
Documented:
. called: "function"
== end:input ==
== begin:output ==
error: Function type specs must use `_` as their subject
== end:output ==
