== begin:description ==
Rejects the same parameterless command signature when two different top-level definition kinds register it.
== end:description ==
== begin:input ==
[\same]
Defines: x is \\anything
Documented:
. called: "same"

[\same]
Theorem:
then: 1 = 1
Documented:
. called: "same"
== end:input ==
== begin:output ==
error: Duplicate command signature `\same` in Theorem; previously defined as Defines in case.mlg:1:2
== end:output ==
