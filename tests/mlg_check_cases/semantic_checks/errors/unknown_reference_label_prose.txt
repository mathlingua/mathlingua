== begin:description ==
Rejects a prose source citing an unknown reference label.
== end:description ==
== begin:input ==
[$some.book]
Resource:
. title: "Some Book"
. author: "Author"

Theorem:
given: x
then:
. (x = x)[:2:]
Proof: "This is ''some text with a source''[:2:] and see (:99:)"
References:
. for: (:2:)
  entry: $some.book
== end:input ==
== begin:output ==
error: Unknown reference label `99`
== end:output ==
